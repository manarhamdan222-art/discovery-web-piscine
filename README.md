# Project 00 — Linux + Git + GitHub

## Introduction

This project is a practical introduction to Linux, Git, and GitHub. It covers basic file management, version control, and working with a remote repository.

## What I Learned

- Navigating directories in Linux.
- Creating and managing files.
- Using Git to track changes.
- Creating commits and viewing Git history.
- Connecting a local repository to GitHub.
- Pushing changes to a remote repository.

## Why Git Makes Development Easier

Git makes development easier by keeping track of changes made to code and files. Version control helps safeguard code because developers can return to an earlier version if a mistake is made.

Git also tracks the history of a project. Each commit records a set of changes, which makes it easier to understand what was changed and when.

Git supports team collaboration by allowing developers to work on the same project, share their changes, and keep the project history organized.

## Git and GitHub Workflow

1. Edit project files.
2. Add changes using Git.
3. Commit the changes.
4. Push the changes to GitHub.
